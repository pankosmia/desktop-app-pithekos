%%APP_NAME%%
Windows %%ARCH%% Portable App

Place all contents of this directory and all subdirectories on any NTFS-formatted drive. NTFS is necessary for this Windows App to be able to save any edits that you make.

Run by double-clicking the "start" file in Windows Explorer.

The file extension connected to the "start" file is ".bat".  It is a "Batch file" that is used to launch this portable app.
